# Prestigebounce — a LiquidBounce theme inspired by the Prestige client GUI

**Short version (tagline):**
> A refined LiquidBounce theme inspired by the Prestige client GUI — deep navy surfaces, soft violet accents, editorial typography, and a complete ClickGUI and HUD editor, all powered by live client data.

**Full marketplace description:**

Prestigebounce is a complete UI overhaul for LiquidBounce, inspired by the clean, modern look of the Prestige client GUI. It replaces the default interface with a calm, editorial design: a deep navy canvas, muted violet accents, elegant serif headings paired with Inter, and generous spacing that keeps even dense module lists easy to read.

The theme is built entirely on real LiquidBounce data. Modules, settings, keybinds, configs, HUD elements and marketplace content are loaded through the client's REST API and synchronized over WebSocket, so toggles, bind changes and HUD values update live while the interface is open. Nothing is mocked or hardcoded.

**Included:**

- Custom ClickGUI with category navigation, search, module cards, per-module settings, keybinds, configs, themes, socials and the marketplace
- Integrated HUD editor with drag-and-drop positioning, per-element settings, enable/disable toggles, live previews and persistent layouts
- Restyled title, multiplayer, singleplayer, alt manager, proxy manager and customize screens
- Custom HUD components, including Watermark, FPS, Ping, Coordinates, PlayerInfo, TabGUI, ArrayList, notifications, TargetHUD, Keystrokes, KeyBinds and inventory overlays
- Custom accent color and optional spaced module names
- Playfair Display and Inter font pairing
- Full compatibility with the LiquidBounce theme system and marketplace

Built with Svelte and TypeScript.
